# Institucional

Pergunta-guia: quem emite certificado hoje na UFRJ, como faz, e onde isso dói?

## Regra de privacidade

Este repositório é público. Aqui entram apenas:

- o roteiro de entrevista;
- o mapa de emissores por **unidade e papel** (ex.: "coordenação de extensão de uma unidade do CCMN"), sem nome ou contato de pessoas;
- sínteses **anonimizadas**.

Gravações, transcrições, termos de consentimento e contatos ficam no Drive do grupo. Se as entrevistas forem usadas em publicação, confirmar antes com a Profa. Maria Luiza a necessidade de submissão a comitê de ética.
